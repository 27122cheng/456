# 台股雷達 Pro — 功能規格總表

這份規格描述「網站現在是什麼」。它的用途有兩個：讓新的 Claude Code 工作階段理解既有設計；以及萬一需要在別處重建時，作為功能清單（重建出來的程式碼不會與現在逐字相同，但功能與架構會一致）。

## 1. 技術基礎
- 純靜態：HTML + 原生 JS + CSS，無框架、無打包、無 npm 相依。`package.json` 僅標示 `type: module`。
- 部署：Vercel。`vercel.json` 把非 `/api/` 路徑重寫到 `index.html`。`api/proxy.js` 為唯一 Serverless 函式：白名單代理、MIS 需帶 cookie／Referer、即時報價不快取、其他 CDN 快取 2 分鐘。
- PWA：`manifest.json` 與 `sw.js`（網路優先、失敗用快取；`CACHE` 版本每次出貨 +1）。
- 狀態：全部在 `localStorage`；設定頁可匯出／匯入（`SYNC_KEYS`）。

## 2. 資料來源與穩健性（js/api.js）
- 日 K：Yahoo v8 chart（6mo）→ 落後 ≥3 個交易日或無資料時走官方：上市 `STOCK_DAY`、上櫃 `tradingStock` 按月抓 14 個月，由新到舊排隊；兩邊合併（`mergeBars`）；官方仍補不齊且有 FinMind token 時走 `TaiwanStockPrice`。
- 官方月線經**節流佇列**（最多 3 並行、150ms 間隔、429 全體暫停 20s 起退避）；月快取帶 `complete` 旗標（當月抓的資料進入下月視為不完整）；查無資料記負快取。
- 過期資料自動重抓：掃描後全部、開個股頁、每 10 分鐘背景；橫幅顯示各來源狀態（`ohlcvFailReason`）。
- 即時報價：證交所 MIS 批次（含五檔）；備援 FinMind（需 token，5 分鐘冷卻）、Yahoo（2 分鐘冷卻）。
- 其他：全市場當日行情（OpenAPI，支援 CORS）、三大法人 T86、融資券、集保股權分散（TDCC）、外資持股、除權息預告（TWT48U）、期貨籌碼（taifex PCR／外資台指期）、月營收、財報、Google News RSS（10 分鐘 TTL）、證交所 OpenAPI 額外資料集（`OAPI_AUTO` 依重要性自動載入，預算 8 項）。
- 熔斷器：代理連續失敗 2 次冷卻 5 分鐘；來源級 `srcMarkDead` 10 分鐘；全部持久化。

## 3. 技術分析（js/indicators.js）
- `calculateScore(ohlcv)`：EMA20/50/200、RSI、MACD、ADX、ATR、布林、量能比、位階百分位、趨勢引擎（phase／maturity／legs／persist／chop）、假突破（Upthrust）、`detectBreakout`（帶量突破／無量突破／出貨／吸籌／突破失敗）、訂單塊（未回補 OB）、量價分佈（POC／VAH／VAL）、Dow 結構、多時框對齊。
- `detectReversal`、`classifyTrend`、`calcSR`。

## 4. 個股研判（app.js `buildManagerAnalysis`）
- 證據加權：技術（趨勢／動能）、量能、籌碼（法人連買賣、外資持股、集保大戶、股東人數、融資券、軋空、五檔、法人買不動／賣不跌背離）、基本面（營收、毛利、本益比歷史）、環境（大盤、族群輪動）、新聞（題材）、風險。
- 證據家族化：每家族貢獻設上限（`FAMILY_CAP`，可由 `familyCapAdj` 依命中率校正）；方向＝家族貢獻和；一致性在家族間計算；信心＝一致性 × 家族數／5。
- 主力誘多／洗盤判別 `trapAnalysis`：位置、量價、假突破、情緒、籌碼、後續六面向，輸出誘多／留意／洗盤／無。

## 5. 大盤看法與預測
- `marketRegime()` 五成分：大盤技術結構 30%、國際連動 25%、市場寬度 20%（含寬度背離）、法人籌碼 15%（含期貨）、大盤量能 10%；`componentAccuracy()` 依歷史命中率調權重。
- 盤性：趨勢／盤整／轉換（ADX＋Choppiness），**遲滯**：原判連 2 個交易日相同才切換；波動位階。
- 預測記錄 `recordPredictions`／`resolvePredictions`（7 日後對答案）、看錯學習 `MARKET_MISS_RULES`、`marketDirProbability()`（單純貝氏校準的 7 日上漲機率，42%~58% 棄權）。
- 資金潮汐／事件行事曆（`getCapitalFlowEvents`、`imminentEvents`）提前 5 天納入簡報與分析。

## 6. 進場推薦管線（`entryEnv` → `evalEntry` → `computeEntrySignals`）
門檻順序：資料過期 → 組合風險已滿 → 回撤斷路器 → 無經驗證優勢 → 大盤逆風（跑贏大盤 ≥10pp 例外）→ 研判強度（均值回歸 0.5、其餘 3）→ 策略型態（含調參門檻）→ 進場計畫 → 已追高 → 風報比（嚴格模式 2.0）→ 流動性（日均成交 ≥3,000 萬）→ 週線逆勢 → 結構站穩（5 日 3 日在 EMA20 上且 EMA20≥EMA50）→ 事件視窗（學習後）→ 排除條件 → 盤整盤位置 → 學習門檻 → 實驗室採用改法 → 利多已反映 → 主力誘多 → 進場品質（含扣分／加分）→ 三支柱缺二 → 族群上限（含持倉與追蹤中訊號，最多 2 檔）。
- 進場品質八因子（位置、趨勢階段、量能、相對大盤、族群內強弱、型態新鮮度、族群輪動、籌碼、一致性、風報比）正規化 100 分；因子權重依贏輸區分力校正（分盤性）；A 級門檻 75（嚴格模式 80）且可自我校準上調。
- 扣分：賠率不對稱、續漲動力薄弱、誘多警訊、除息／財報／月營收視窗、週線無趨勢、與持倉高相關、跳空頻繁、目標偏遠、實績低勝率情境；加分：實績高勝率情境。
- 嚴格模式：大盤偏空或盤性轉換。
- 進場計畫 `buildEntryPlan(s, m, {mode, tuned})`：掛買區、停損（結構／ATR／實證 MAE 收緊／跳空風險註記）、目標（真實壓力區；無壓力續抱）、三情境、續漲動力鏈、部位（停損法／災難法／流動性上限／零股／冷卻／Beta）、分批計畫、事件、週線、流動性；策略覆寫（均值回歸：回 EMA20 即走；動能續抱：吊燈停損；調參：固定 R 目標與停損上限）。

## 7. 紙上交易與學習
- `recordAiSignals`／`updateAiSignals`（simVer 98）：限價進場區、成交前破停損記未成交、成交當日破停損記停損、+1R 減半保本、續抱型移動停利、固定目標 20 日／續抱 40 日到期、跳空以開盤價成交、淨報酬扣稅費。
- 止損學習：波段 `SWING_LOSS_RULES`（含事件跳空、週線無趨勢、流動性偏薄、跳空跳過停損、目標偏遠、追老化突破）、當沖 `DT_LOSS_RULES`、長期剔除學習；全部經 `learnGate` 安全閥。
- 期望值統計 `expectancyStats`（淨 R、MAE90、半凱利）、情境分組 `expectancyBySituation`（含籌碼／基本面／題材／盤性／策略）。
- 系統冷卻（連虧 3 或最近 20 筆淨 R 為負 → 減半）、回撤斷路器（最近 30 筆權益回撤 ≥6R → 停手，10 日後且最近 3 筆回正自動解除）。

## 8. 策略實驗室（交易總結頁）
- 波段改法實驗室 `runSwingLab()`：13 個改法各自套回全池真實日 K，70/30 時間切分，只看驗證段判定；疊加有效改法再驗；一鍵採用成硬門檻；每 5 個交易日自動重跑。
- 策略庫 `SWING_STRATEGIES` 分盤性冠軍 `pickChampions`；`currentSwingStrategy()` 依今日盤性切換；優勢閘門（設定頁可關）。
- 目標導向調參 `tuneStrategy`：訓練段在「n≥25、期望值 ≥+0.1R、回撤 ≥−4R」內找最高勝率參數，驗證段打分；MAE／MFE 實證距離；採用後接進實盤。
- 當沖實驗室：`DT_STRATEGIES` 10 策略走動式驗證、分盤性冠軍、自動調參（有界）。
- 技術訊號歷史回測 `runBacktest`、`backtestLessons`。

## 9. 持倉管理
- `checkHoldingExit`：停損、研判轉空、均線雙破、頂背離、外資賣超、營收轉差、目標達成、財報截止、除息預告、時間停損（40／120 日）、誘多 vs 洗盤、買進理由檢查 `thesisCheck`、健康度 `holdingHealth`。
- `updateTrailingStops`：+1R 成本、+2R 結構位、動能續抱吊燈停損、時間衰減（10 日仍在 ±0.5R → 收至 −0.5R）。
- 組合風險 `portfolioHeat`（總停損額上限 6%／盤整轉換 4%、族群集中、60 日相關）。
- 盤中停損逼近／觸發推播 `checkStopProximity`。

## 10. 當沖
- `computeDayTradePicks` 多空雙向：流動性、波動覆蓋全成本（稅費＋tick 價差）、日線與週線同邊、法人籌碼、大盤方向、日內相對強度、ORB／VWAP 進出場、掛單價含通知緩衝；紙上追蹤 `dt-trades`、13:00 平倉提醒、收盤前出清。

## 11. 介面
- 推薦交易頁：行動摘要條（可進場／觀察／當沖／長期／大盤／波段策略／出手模式）、直觀訊號卡（等級圓章、🟥停損・🟦掛買・🟩目標、價位尺、一句話理由、紀律、警示、升級條件、詳細收合）、篩選漏斗收合。
- 持倉卡：狀態圓章、報酬大字、三價位、現價標記價位尺、「下一步」一句話。
- 個股頁：研判、進場建議（三價位＋價位尺＋紀律＋門檻體檢）、型態／誘多卡、籌碼、基本面、多時框、風險。
- 交易總結頁：學習總覽（含斷路器、系統健康、門檻校準）、期望值、AI 成績單、止損學習、回測、波段改法實驗室、大盤預測準確度、教訓學習、交易紀錄。
- 設定頁：資金、可接受最大虧損、優勢閘門、Telegram、FinMind token、OpenAPI 資料目錄、匯出匯入。

## 12. Telegram
- 三報：08:30 盤前（昨收、夜盤、新聞、數據、事件、開盤研判）、09:30 開盤後、16:30 盤後總結；進場訊號（結構化三價位）、持倉檢查、當沖觸發與平倉提醒、停損逼近；全部日曆日去重。

## 13. 測試框架（Node，無相依）
建立 `run_ob.js`：以 Proxy 模擬 `localStorage`（`Object.keys` 需回傳已存鍵）、`document.getElementById` 回傳空元素、`fetch` 拒絕、`setInterval` 無作用；讀取三支 JS 與測試檔串成一個字串 `eval`，提供 `T(name, cond)`／`done(label)`／`synthBars()`／`mkStock()`。測試以 `inner_*.js` 分主題（冒煙、進場門檻、歷史抓取、訊號卡、持倉卡、準確度、實驗室、策略庫、風控、調參）。
